# Krishna CRM

Comprehensive Customer Relationship Management (CRM) system comprising:
- **`backend/`**: Node.js / Express backend service with MySQL, JWT authentication, WhatsApp business integration, SmartOffice biometric sync, and AWS S3 storage.
- **`frontend/`**: Next.js / React frontend web application with Tailwind CSS dashboard.

## Project Structure

```text
krishna/
├── backend/    # Express API server, database models, migrations & services
└── frontend/   # Next.js web application UI & components
```

## Getting Started

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
